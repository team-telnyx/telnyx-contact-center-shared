<ChangelogEntry
  title="AI Tools Library and Insights administration"
  date="2026-07-11"
  pr="https://github.com/team-telnyx/telnyx-contact-center/pull/1243"
>
  Added Admin workspace pages for Tools Library and Insights. The tools page
  includes filtering, pagination, create/edit sheets, per-tool editors,
  webhook testing, assistant assignment, and delete flows. The insights page
  adds insight cards, schema and instruction editing, group editing, and
  assign/unassign APIs.

<ChangelogEntry
  title="Telnyx AI Assistant administration"
  date="2026-07-11"
  pr="https://github.com/team-telnyx/telnyx-contact-center/pull/1242"
>
  Added the Admin AI Assistants list, create, and editor views modeled on the
  Telnyx demo portal. The editor now covers Dashboard, Agent, Voice, Workflow,
  Integrations, Insights, Calling, Messaging, Widget, Privacy, and
  Conversations, including conversation sheets, call/session details,
  recording playback, transcript seeking, costs, version actions, traffic
  distribution, chat, call, clone, save-as-version, and deletion.
</ChangelogEntry>
