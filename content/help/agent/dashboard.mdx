Choose **Dashboard**, select **Today**, **7 days**, or **30 days**, and use Refresh when current data is needed.

The overview includes Calls handled, Completion rate, Average handle time, Talk time, Occupancy, Holds, Transfers, and Break time. Charts show call outcomes, calls by assigned queue, hourly completed/abandoned activity, and personal wrap-up-code distribution.

Interpret metrics in context: handle time includes the configured lifecycle of the interaction; occupancy compares work time to available tracked time; a transfer or hold count describes events, not necessarily service quality. Use the same date range when comparing cards and charts.
