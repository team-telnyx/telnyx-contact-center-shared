Activate campaigns from the header. An available assignment appears in Desktop as **Outbound Campaign Record** with campaign name, destination, mode, contact fields, and a call action.

In Preview mode, inspect the record and choose **Start outbound call** when ready. In Progressive mode, the record shows the remaining automatic-dial countdown; the call starts when it reaches zero unless campaign state changes. Starting an assignment sets the operational status to **On Outbound Call**.

After the call, **Campaign Disposition** requires a mapped disposition code. The classification controls whether the record completes, retries, schedules callback, or becomes suppressed/uncallable. If the selected code requires callback, enter date and time. Notes are optional but should contain operationally useful information without unnecessary sensitive data.
