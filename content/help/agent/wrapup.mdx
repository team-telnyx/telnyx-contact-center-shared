After an answered call ends, the global **Wrapup Codes** sheet opens and status changes to **Wrapup**. Calls that were never answered, timeout/re-enqueued calls, customer abandonment before answer, and consult-only legs do not create normal wrap-up.

The sheet shows the queue, countdown to auto-save, and codes assigned to that queue. Select all codes that accurately describe the outcome. A code can show a description, icon/color, and **Default** badge.

Choose **Save & Close** before the timer expires. If time expires or the sheet is dismissed during normal operation, the selected/default codes are auto-submitted. When saving fails, use **Retry save**; **Close without saving** is exposed only as recovery from a failed save.

Successful completion records the disposition and returns status to Available. Do not start unrelated work while wrap-up is open. Campaign calls can additionally open **Campaign Disposition**, where the selected mapping may require callback date/time and allows supervisor/reporting notes.
