The header remains available while navigating the application.

| Control | Function |
| --- | --- |
| Sidebar button | Expands or collapses the main left menu. |
| Docs | Opens the documentation center. Press **F1** for contextual screen help. |
| Status selector | Shows the current agent status and allows selection of statuses marked user-selectable. |
| Campaigns `active/total` | Activates eligible outbound campaigns and shows campaign state/mode. |
| Queues `active/total` | Activates queues and shows each queue routing strategy. |
| WebRTC Phone | Opens or hides the shared browser phone and reflects its current call state. |

Agent controls appear only for a user who has the `agent` role. Supervisor, admin, or owner access does not automatically show them unless that same account also has the agent role.

Status, queue, and campaign changes are updated in real time. If the shared event stream is unavailable, status uses fallback polling. A newly created queue can generate a **New queue available** notification; it is not activated automatically.

## Call device and personal preferences

The phone panel's **Calls on** control identifies the selected destination for future calls. Choose a ready device before expecting voice offers. Moving an active call uses a separate handoff action; follow [Devices and call handoff](/help/webrtc-phone/devices).

Use the account menu's [Profile](/help/profile) for interface language, speech language, personal notification sounds, security and device management. A microphone selector changes audio input on the current device, not the destination that takes calls.
