| Section | Detailed use |
| --- | --- |
| Forms | Open queue/interaction-assigned forms, complete required fields, and submit configured buttons/Data Actions. Keep the correct interaction selected so context and interaction IDs are mapped correctly. |
| Contacts | Search contact records and use a stored number for calling. Verify the selected number when a contact has several phone fields. |
| Tasks | Search and manage work items; create or associate contact information where the task UI provides that action. Keep due date, assignee, state, and notes current. |
| KB Articles | Search approved internal guidance. Verify relevance and revision before reading guidance to the customer. |
| Web Pages | Open portals approved by administrators. Authentication and permissions belong to the target site; never paste secrets into customer-visible fields. |

These views do not change the selected interaction automatically. Use **Back to interaction** where shown to return to the live assistance panel.

For forms, submission success and Data Action success are separate states. Read the returned status, preserve entered data after recoverable errors, and avoid clicking an action repeatedly when its external operation may not be idempotent.
