Open **AGENT → Desktop**. Agent Workspace combines live interactions, Agent Assist, queue forms, customer data, tasks, knowledge articles, web pages, performance metrics, outbound campaign records, and WebRTC call controls.

## Recommended daily sequence

1. Allow browser microphone access and select the intended audio devices in [WebRTC Phone](/help/webrtc-phone).
2. In the application header, select a user-selectable status and activate the queues or campaigns assigned for the shift.
3. Keep **Desktop** open for offered interactions. Answer and control the call in WebRTC Phone.
4. Use the selected interaction panel for the configured Agent Assist mode and the rail for supporting data.
5. After an answered call ends, complete wrap-up before accepting the next interaction.
6. Before leaving, deactivate queues/campaigns and choose the appropriate non-available status.

## Agent rail

| Section | Function |
| --- | --- |
| Desktop | Live interaction list and configured interaction assistance. |
| Dashboard | Personal call, handling-time, occupancy, hold, transfer, queue, and disposition metrics. |
| Forms | Forms assigned through queues or interaction configuration. |
| Web Pages | Approved external portals embedded for agent use. |
| Contacts | Search customer/contact records. |
| Tasks | Search, create, update, and organize work items. |
| KB Articles | Search the internal knowledge base. |

The selected interaction is retained locally where possible, but completed or reassigned interactions disappear from the active list. Treat the server status and current interaction state as authoritative.
