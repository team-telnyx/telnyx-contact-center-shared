Choose a rail section, drag blocks onto the active page, select a block, and edit its properties. Container blocks can hold nested children; child layout controls set alignment and grid spans.

Use stable field IDs and variable names before wiring actions. Preview at the width agents use, not only on a wide admin screen. Keep labels visible, help text concise, and related fields in one section. The **Exit** rail item returns to the Forms gallery; save or verify changes before leaving.
