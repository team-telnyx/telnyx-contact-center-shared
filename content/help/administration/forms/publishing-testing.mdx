Before publishing, preview every page at agent width, complete the form with representative and boundary data, and inspect the stored submission and every action result. Test required fields, choices, boolean false, zero, dates/time zones, long text, missing context, keyboard navigation, focus order, and action errors.

Publishing makes the current definition available to intended consumers. Confirm queue assignments and auto-open behavior first. Export a JSON backup before structural changes. Use Archive when the form should disappear from active use but submissions or audits may still refer to it.
