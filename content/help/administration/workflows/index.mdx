Open **Admin → Automations → Workflows**. A workflow is an ordered set of stages and items analyzed against the conversation. It guides the agent, detects completion, and captures data slots.

Search and filter the list by category and status. Use **New Workflow**, edit, duplicate, export, import, test, or delete. Duplicates and imports are inactive until reviewed. Exported content does not replace environment-specific assistant configuration.

Build the structure first, configure precise item semantics, then use the test module before activation. Deleting a workflow also removes its stages and items; remove operational assignments and export a backup first.
