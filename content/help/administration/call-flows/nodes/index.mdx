Every page in this section describes one node type. Configure the node, connect every result that matters, and validate the graph. Output names shown in the editor are authoritative because they determine which edge runs.

Initiators start a graph. Call-control and media nodes operate on the call. Logical nodes select paths or create data. Integration nodes exchange data with external systems. Start/stop pairs should normally be balanced on success, error, and hangup paths.

Use [Variables](../variables), [Expressions](../expressions), and [Edges](../edges) with this reference.
