---
title: Form Submit
description: Start a data-action flow from a form button submission.
---

**Form Submit** is the initiator for a form Data Action. It receives form, submission, button, field values, variable values, context, and interaction data under the configured payload variable (default `form_payload`).

Connect only app-flow-compatible nodes and finish with Form Submit Status or Flow End. Keep form variable names stable, validate required context, and add an error result for failed external actions.
