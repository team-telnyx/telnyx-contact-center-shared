---
title: Data Action
description: Execute a configured data-source operation and map its result.
---

**Data Action** runs an available operation against a configured Data Source, using mapped inputs and a response variable/schema.

Choose the exact operation, validate required inputs and permissions, then use response-schema paths in edge mappings. Handle not-found, validation, authorization, timeout, and provider error results separately; do not expose unrestricted data operations to untrusted payload values.
