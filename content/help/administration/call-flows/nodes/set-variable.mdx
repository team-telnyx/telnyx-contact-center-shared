---
title: Set Variable
description: Create or update a custom runtime variable from an expression.
---

**Set Variable** evaluates an expression and stores the result under a custom name. Names must start with a letter or underscore, contain only letters/numbers/underscores, and not be reserved words.

Use the Expression Editor and test the resulting type. Avoid changing a variable from one type to another later in the flow. Connect error handling when parsing or conversion can fail.
