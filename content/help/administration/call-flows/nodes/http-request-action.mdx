---
title: HTTP Request action
description: Call an external HTTP endpoint and use its response downstream.
---

This node sends an outbound HTTP request with configured method, URL, headers, query/body, timeout, and response variable. Fields may use templates/expressions.

Test the request in the editor, map stable response paths, and connect success, non-success, timeout, and error outputs. Put credentials in Secrets, validate URLs, set bounded timeouts, and never assume a 2xx body has the expected schema.
