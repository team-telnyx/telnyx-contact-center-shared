---
title: MCP Tool
description: Invoke a tool exposed by a configured MCP server.
---

**MCP Tool** selects an MCP server/tool, maps arguments from expressions, and stores the response for downstream use.

Confirm the server is enabled, credentials are configured through Secrets, and argument names/types match the current tool schema. Connect success, tool error, timeout, and invalid-response paths; map only required response properties.
