Open **SUPERVISOR → Analytics**, select a report in the rail, then set quick/custom date-time range and filters. Refresh after changing the scope when the screen does not load automatically.

| Report | Measures and recommended use |
| --- | --- |
| Queue Performance | Offered, answered, abandoned, answer rate, service level at the configured SLA threshold, daily volume/outcomes, average wait trend, and weekday/hour heatmap. Use it for staffing and SLA review. |
| Agent Scorecard | Active agents, handled/completed volume, AHT, occupancy, holds, transfers, top agents, and daily handled volume. Compare like-for-like queue assignments and schedules. |
| Abandonment | Abandon count/rate, wait-time buckets, worst queues, hourly answered/abandoned pattern, and callback candidates. Investigate short abandons separately from long waits. |
| Adherence | Agents tracked, logins, status changes, time by status, breaks, and recent transitions. Interpret against schedules and approved exceptions. |
| Transfers & Holds | Transfer rate/count, hold events/rate, average/maximum hold duration, and pressure by queue/agent. Use outliers as investigation leads. |
| Wrap-up Codes | Coded interaction count, coverage percentage, distinct codes, disposition mix, and uncoded work. Low coverage can invalidate downstream cause analysis. |
| AI Handoffs | AI-to-agent handoff volume, outcomes, timing, and health. Compare handoff reason with final disposition and queue result. |
| Outbound | Campaign attempts, connect rates, outcomes, and failure reasons. Segment by campaign/mode before drawing conclusions. |
| Skills Gap | Skill demand versus available agent supply and queue coverage. Use with live relaxation indicators before changing proficiency requirements. |
| Call History | Searchable interaction records with recordings, transcript, timeline, metadata, and workflow details. |

Analytics aggregates depend on lifecycle events and selected timestamps. Avoid adding percentages from reports with different denominators. Export/screenshot only according to customer-data handling policy.
