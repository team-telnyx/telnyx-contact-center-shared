# Telnyx Contact Center - Video Demo Script

**Target Duration:** 8-10 minutes  
**Language:** English  
**Style:** Professional, conversational, clear

---

## 📋 Demo Structure Overview

| Section | Duration | Focus |
|---------|----------|-------|
| Intro | 0:30 | Welcome, product overview |
| Administrator | 4:00 | Configuration & setup |
| Supervisor | 2:00 | Monitoring & analytics |
| Agent | 2:30 | Daily operations |
| Outro | 0:30 | Summary & CTA |

---

## 🎬 INTRO (0:00 - 0:30)

### Scene: Login screen → Dashboard

**Voice Over:**
> "Welcome to Telnyx Contact Center — a modern, cloud-native solution for managing your customer communications. Built on Telnyx's global voice network, it combines powerful administration tools, real-time supervision, and an intuitive agent experience. Let's take a tour."

---

## 👔 SECTION 1: ADMINISTRATOR (0:30 - 4:30)

### 1.1 Users Management (0:30 - 1:00)

**Scene:** Admin → Users page

**Voice Over:**
> "As an administrator, you have full control over your contact center. Let's start with user management. Here you can create agents, supervisors, and other admins. Each user can be assigned multiple roles, and you can set their skills and proficiency levels directly from their profile."

**Actions to show:**
- User list with roles badges

### 1.2 Skills-Based Routing (1:00 - 1:30)

**Scene:** Admin → Skills page

**Voice Over:**
> "Skills are the foundation of intelligent call routing. Define skills like 'Spanish', 'Technical Support', or 'Billing', then assign them to agents with proficiency levels from 1 to 10. The system automatically routes calls to the best-matched available agent."

**Actions to show:**
- Skills list
- Click to edit a skill
- Show skill assignment on user profile

---

### 1.3 Queues Configuration (1:30 - 2:00)

**Scene:** Admin → Queues page

**Voice Over:**
> "Queues are where calls wait for the right agent. Configure required skills, priority levels, and SLA thresholds. The system supports skill relaxation — if no perfect match is available, requirements gradually relax to ensure calls are answered."

**Actions to show:**
- Queue list with stats
- Edit queue → show skills requirements
- Highlight SLA and priority settings

---

### 1.4 Call Flows Designer (2:00 - 3:00)

**Scene:** Admin → Call Flows → Open flow editor

**Voice Over:**
> "The visual Call Flow Designer is where you build your IVR logic. Drag and drop nodes to create sophisticated call handling — from simple greetings to complex routing decisions. Connect to external APIs, play audio prompts, collect digits, and route calls to queues or specific agents."

**Actions to show:**
- Open an existing call flow
- Show the visual canvas with connected nodes
- Click on a node to show configuration (e.g., Speak node, Gather node)
- Highlight different node types: Answer, Speak, Gather, Enqueue, AI Assistant
- Show the node palette on the left

**Voice Over (continued):**
> "Each node type serves a specific purpose — Answer to pick up the call, Speak for text-to-speech, Gather to collect input, and Enqueue to route to your queues. You can even integrate AI assistants directly into your flows."

## 🎵 Production Notes

### Music
- **Style:** Light, modern, corporate-friendly
- **Volume:** Low background, ducking under voice over
- **Suggestions:** Upbeat but not distracting, no lyrics

### Transitions
- Clean cuts or subtle fades between sections
- Section title cards (optional): "Administrator", "Supervisor", "Agent"

### Pacing
- Allow 1-2 seconds of "breathing room" between sections
- Match voice over timing to on-screen actions
- Don't rush — clarity over speed

### Screen Recording Tips
- Use 1920x1080 resolution
- Hide bookmarks bar and unnecessary browser UI
- Use sample data that looks realistic
- Pre-populate forms where needed to avoid typing delays
